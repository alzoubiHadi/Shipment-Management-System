# ALBA — تطبيق إدارة الشحن البري

تطبيق لإدارة عمليات وسيط الشحن البري (شركة **ALBATRANS L.L.C.**، دبي، الإمارات) يربط بين ثلاثة أطراف: **الأدمن** (يدير كل العمليات)، **السائقين** (ينفذون الشحنات)، و**الشركات** (عملاء يطلبون شحن بضائعهم).

## الفكرة العامة

الشركة العميلة لا تُنشئ طلب شحن مباشرة عبر التطبيق (تتصل أو تراسل الأدمن كما يحدث فعلياً بهذا النوع من الأعمال). يسجّل الأدمن الطلب كـ"عرض شحن" (Shipment Offer)، والنظام يعرضه فقط على السائقين المؤهلين حالياً (متاحين، وثائقهم سارية، ويحقّقون شرط الإقامة إن كان الشحن عابراً للحدود)، وأول سائق يقبله يحصل على الشحنة ويبدأ بتنفيذها عبر مسار تتبع من 7 مراحل ينتهي بتوقيع رقمي لإثبات التسليم.

## البنية التقنية

| الطبقة | التقنية |
|---|---|
| الواجهة (Client) | Flutter (Dart) — يعمل على أندرويد والويب من نفس الكود |
| الخادم (API) | Laravel 12 (PHP) — واجهة REST API |
| قاعدة البيانات | SQLite |
| المصادقة | Laravel Sanctum (Token-based) |
| الاختبارات الآلية | PHPUnit (11 اختبار Feature Test) |

## أبرز الميزات

- تسجيل دخول/تسجيل ذاتي بثلاثة أدوار (سائق، شركة، أدمن) مع Laravel Sanctum.
- سوق عروض شحن: إنشاء العرض من الأدمن، مطابقة تلقائية مع السائقين المؤهلين، وقبول بمعاملة قاعدة بيانات آمنة (قفل ضد التسابق).
- قواعد عمل حقيقية: تأهيل السائق (وثائق سارية)، قاعدة الإقامة لعبور الحدود (3 أشهر)، تطابق نوع الشاحنة، شرط التبريد للحمولات المبرّدة.
- مسار تتبع شحنة من 7 مراحل مع توقيع رقمي (Proof of Delivery) مرسوم يدوياً بالتطبيق.
- تحديث شبه لحظي (Polling كل 5 ثوانٍ) لشاشة التتبع لدى الأدمن/الشركة.
- تقارير: أداء كل سائق، إحصائيات كل شركة وأكثر وجهاتها طلباً، وملخص العمولة الإجمالية.
- إدارة كاملة للسائقين والشركات والشاحنات (إضافة/تعديل/حذف ناعم/استعادة).

## هيكل المشروع

```
Trucks/
├── app/       ← تطبيق Flutter (lib/Screens, lib/API, lib/models)
└── server/    ← خادم Laravel (app/Http/Controllers, app/Models, database/migrations, tests)
```

## تشغيل المشروع محلياً

### الخادم (Laravel)

```bash
cd server
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

### التطبيق (Flutter)

```bash
cd app
flutter pub get
flutter run -d chrome   # أو flutter run لجهاز أندرويد متصل
```

### تشغيل الاختبارات الآلية

```bash
cd server
php artisan test --filter=ShipmentBusinessRulesTest
```
